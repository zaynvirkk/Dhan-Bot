How this strategy decides

CAS_LAG_V1 compares the official auction value with a reference frozen from five accepted index observations before continuous trading closes. Above the reference it considers calls; below it, puts.

A contract needs at least two qualifying observations, bid and ask depth for a whole lot, and a positive conditional edge after fees within the bot’s capital limits. Candidates are ranked by conditional return, then cash edge. The final-value path uses a separately verified closing value.

It exits on convergence, reversal, invalidation or the time limit. These are the auction rules. The enabled engines and their individual checks are listed above.

        Operator controls & setup

        VM commands

        Run these commands yourself on the VM. Viewing this page never enables trading.

        Connect to the existing Google Cloud VM

        Use a terminal with your Google Cloud login.

        gcloud compute ssh sablestone-dhan-cas --zone=asia-south1-a --project=project-cead8bae-10ea-4ea9-875 --tunnel-through-iap
        Check the deployed bot before activation

        Confirm the configured strategies and their input checks above. Connection checks and the activation preflight do not establish profitability. Resolve any failed feed checks before enabling orders.

        sudo systemctl start dhan-cas-connections.service
sudo cat /var/lib/sablestone-dhan/connections.json
sudo /opt/sablestone-dhan-cas-bot/.venv/bin/python /opt/sablestone-dhan-cas-bot/ops/activate-live.py --capital available --check-only

        If preflight reports an outdated software verification, run the deployed bot’s verification and inspect the result. Do not disable its checks.

        Enable real-money execution

        This operator command allocates the available reusable cash, enables automatic broker orders and starts the service. That includes its bounded order-route probe. Existing sizing limits still apply. It does not install a different research strategy.

        sudo /opt/sablestone-dhan-cas-bot/.venv/bin/python /opt/sablestone-dhan-cas-bot/ops/activate-live.py --capital available

        Check the bot’s fresh status afterward. This dashboard has no activation endpoint.

        Pause new entries and inspect status

        Pausing new entries preserves exit and reconciliation handling.

        sudo -u sablestone /opt/sablestone-dhan-cas-bot/.venv/bin/dhan-cas disarm --config /etc/sablestone-dhan/production.toml --new-entries
sudo cat /var/lib/sablestone-dhan/status.json
